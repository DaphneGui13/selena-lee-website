# Serena Lee Photography

One-page site for wedding and portrait photographer Serena Lee. Plain HTML and CSS, no build step.

## Structure

- `index.html` is the whole page.
- `images/` holds the portfolio photos. Replace the placeholders in `index.html` with `<img src="images/your-file.jpg">`.
- `vercel.json` sets clean URLs and long caching for images.

## Deploy on Vercel

1. Import this repository at https://vercel.com/new.
2. Set Framework Preset to **Other**. Leave Build Command and Output Directory empty.
3. Deploy. Every push to `main` redeploys.

## Run locally

Open `index.html` in a browser, or run `npx serve .`.

## Before launch

Replace the placeholder email `hello@serenalee.com` with Serena's real address.
